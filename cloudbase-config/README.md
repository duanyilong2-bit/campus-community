# CloudBase 安全配置清单

本目录记录校园社区当前需要在 CloudBase 控制台核对的配置，不包含密码或密钥。

## 数据库权限

小程序前端没有直接访问云数据库，全部业务读写都通过云函数完成。因此所有业务集合应设置为“仅管理端可读写”。这样用户无法在调试器中直接篡改任务、订单、身份、金额和状态。

云存储建议设置为“仅创建者可读写”。用户只能上传和清理自己创建的文件，业务云函数仍可读取并生成临时访问地址。

## 索引

`database-indexes.json` 是按照当前查询条件整理的索引清单。`orders.taskId` 建议设为唯一索引，作为数据库层的第二道重复订单保护；建立前需要先确认历史 orders 中没有重复 taskId。

索引和控制台权限属于环境配置，不能仅靠上传小程序代码自动生效，需在 CloudBase 控制台核对。
